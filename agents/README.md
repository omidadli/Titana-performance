# Agent‌ها — اجرای فاز ۱ با هوش مصنوعی (Claude / ChatGPT متصل به GTM و GA4)

> کارهای فنی فاز ۱ را می‌توانی به دو Agent بدهی: **Agentِ GTM** (متصل به کانتینر) و **Agentِ GA4** (متصل به پراپرتی). این پوشه پرامپت‌های آماده‌ی هرکدام است.

## نقش‌ها و مرزها (کی چه چیزی می‌کند)

```
[تیم برنامه‌نویسی]          [Agent GA4]                [Agent GTM]                [تو — دستی]
dataLayer (T1-T7)      →   تنظیمات پراپرتی GA4  →   تگ‌ها/تریگرها/متغیرها  →   پنل یکتانت و تپ‌سول
(dev-tasks.md بخش A)      (پرامپت: پراپرتی)        (پرامپت: کانتینر)            (تسک‌های ۱۳ تا ۱۵ فاز ۱)
                                                                      ↘
                                                                    [تو: Publish + اعتبارسنجی نهایی]
```

**قانون طلایی:** هیچ Agent بدون دستور صریح تو **Publish/تغییر نهایی** نمی‌کند. Agent‌ها «آماده‌سازی + گزارش» می‌کنند؛ «تأیید و انتشار» با توست.

## ترتیب اجرا (فاز ۱)

| مرحله | کار | مسئول | توضیح |
|---|---|---|---|
| 1 | تسک‌های P0 (`dev-tasks.md` بخش A) | تیم برنامه‌نویسی | بدون dataLayer، Agentِ GTM چیزی برای خواندن ندارد. **اولین قدم** |
| 2 | `prompt-ga4-agent.md` | Agent GA4 | مستقل از بقیه؛ هم‌زمان با مرحله ۱ قابل اجراست |
| 3 | `prompt-gtm-agent.md` | Agent GTM | بخش ممیزی (T-G1) را می‌شود قبل از dataLayer هم اجرا کرد؛ بقیه بعد از dataLayer |
| 4 | پنل یکتانت + تپ‌سول (تسک‌های ۱۳-۱۵) | **تو (دستی)** | این Agent‌ها به پنل‌های شبکه‌های ایرانی دسترسی ندارند؛ کد Conversion را از پنل می‌گiri و به Agent GTM می‌دهی تا تگ Custom HTML را بسازد |
| 5 | Publish + ماتریس تست (تسک ۲۲-۲۴) | تو + Agent‌ها | Agent GTM در Preview تست می‌کند؛ تو Publish می‌کنی؛ اعتبارسنجی سه‌جانبه (GA4+یکتانت+تپ‌سول) با یک خرید تست واقعی |

## نحوه استفاده (هر Agent)

1. فایل پرامپت مربوطه را باز کن
2. فایل‌های پیوستِ اعلام‌شده در ابتدای پرامپت را به Agent بده
3. متن بین `--- شروع پرامپت ---` و `--- پایان پرامپت ---` را کپی و بفرست
4. گزارش Agent را بگیر → موارد «بلوک‌شده» و «نیاز به تصمیم» را حل کن → قدم بعدی
5. **هر Agent فقط یک پرامپت دارد** (GTM یا GA4) — پرامپت‌ها را با هم قاطی نکن

## چرا این‌طور چیده شده؟

- **دو Agent، نه یک Agent برای همه‌چیز:** Agentی که هم به GTM و هم به GA4 وصل باشد، تمایل به «تصمیم‌های ترکیبی» دارد (مثلاً خودسرانه event را در GA4 بسازد). مرز وظایف = داده‌ی تمیز.
- **پرامپت‌ها «منفی» هم دارند:** هر پرامپت صریح گفته چه چیزی **نمکند** بکند (حذف تگ، حذف پراپرتی، Publish بدون اجازه). این مهم‌تر از لیست تسک‌هاست.
- **خروجی ساختاریافته:** هر Agent گزارش یک‌فرمت برمی‌گرداند؛ گزارشِ Agentِ GA4 ورودیِ قدم بعدی تو می‌شود، نه یک دیوار متن.
- **Agent به پنل‌های یکتانت/تپ‌سول دسترسی ندارد:** این‌ها را دستی انجام می‌دهی (هرکدام زیر ۳۰ دقیقه با پرامپتِ داخل تسک‌های ۱۳-۱۵ فایل فاز ۱).
