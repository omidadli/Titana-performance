# فاز ۱ — بنیان داده (هفته‌ی ۳ تا ۶)

## هدف فاز (یک جمله)
**همه‌ی کارهای کلیدی سایت — خرید و هر نوع لید — با پارامتر درست به سه مقصد برسد: GA4 + یکتانت + تپ‌سول.**

> وقتی این فاز تمام شد، جمله‌ی دقیق این است: **«زیرساخت جمع‌آوری داده ساخته شد.»** و در فاز ۲ سراغ داشبورد می‌رویم — دقیقاً همان زنجیره‌ای که باید بود.

**۳ کار مهم‌ترین این فاز:** تسک ۱۶ (dataLayer e-commerce — ارجاع به تیم فنی) · تسک ۲۰ (user_id = شماره‌ی موبایل در لیدها) · تسک ۲۲ (اعتبارسنجی سه‌جانبه‌ی یک خرید واقعی)

---

## معماری نهایی داده (هدف این فاز)

```
                         ┌────────────────────────────────────────────┐
                         │            سایت (وب‌بیت)                    │
                         │  dataLayer استاندارد (یکجا، مرتب)          │
                         └───────────────────┬────────────────────────┘
                                             │  فقط یک اسکریپت (GTM)
                                             ▼
                         ┌────────────────────────────────────────────┐
                         │          کانتینر GTM (تنها لایه‌ی تگ)       │
                         │  تگ‌ها: GA4 Configuration + 6 رویداد GA4    │
                         │        + 1 تگ Conversion یکتانت            │
                         │        + 1 تگ Conversion تپ‌سول             │
                         └──────┬──────────────────┬──────────────────┘
                                ▼                  ▼
                          ┌──────────┐       ┌──────────────────┐
                          │   GA4    │       │  یکتانت + تپ‌سول  │
                          │ همه‌ی ۶   │       │  purchase +      │
                          │ رویداد   │       │  generate_lead   │
                          └──────────       └──────────────────
                                
  [پنل وب‌بیت] ── CSV ماهانه ──► [شیت «هزینه و فروش آفلاین»] ──► (فاز ۲: داشبورد)
```

**اصل:** صفحه‌ی سایت فقط dataLayer می‌ریزد. هر تگ (GA4، یکتانت، تپ‌سول) از طریق **یک کانتینر GTM** مدیریت می‌شود. یعنی: هیچ کد اضافی در صفحه، هر تغییری در GTM است (نه در کد)، و هر چیزی را می‌توان Preview/Debug کرد.

### در فاز مقدماتی **نباید** این کارها را بکنیم (خروج از محدوده، صریح)
- ❌ Server-side tagging (بعداً، اگر واقعاً ضرورت شد)
- ❌ BigQuery / داده‌ی کلان (با حجم فعلی B2B اصلاً به آن نمی‌رسیم)
- ❌ CDP / CRM جدید (فروش فعلی در شیت + پنل وب‌بیت می‌چرخد؛ CRM فاز ۴/۵ و فقط اگر تیم بزرگتر شود)
- ❌ پیکسل شبکه‌های خارج از ایران (متا/گوگل — فعلاً تبلیغات روی یکتانت/تپ‌سول است؛ وقتی کانال جدید آمد، «قالب فاز ۱» را تکرار می‌کنیم — در فاز ۵)
- ❌ بیش از ۶ رویداد سفارشی (هر رویداد اضافی = هزینه‌ی نگهداری + گیجی گزارش‌ها)

## لیست ۶ رویداد اصلی (کل این فاز را حول این ۶ اسم می‌چرخیم)

| رویداد | کجا می‌افتد | مهم‌ترین پارامترها |
|---|---|---|
| `view_item` | صفحه‌ی محصول + صفحه‌ی مدل/سایز (`/model/...`) | `items[]` (id, name, brand, price, variant, currency) |
| `add_to_cart` | بعد از انتخاب سایز و افزودن به سبد | `items[]` + `value` |
| `begin_checkout` | ورود به چک‌اوت از سبد | `items[]` + `value` |
| `purchase` | **صفحه‌ی موفقیت پرداخت** (نه خود گیت‌وی) | `transaction_id` + `value` + `currency` |
| `generate_lead` | دانلود لیست قیمت / کاتالوگ / فرم / واتساپ / تلگرام / بله / تماس / چتbot «تینا» | `lead_method` (8 مقدار — در واژه‌گان داده) + `page_location` |
| `search` | نتیجه‌ی جستجوی داخلی سایت | `search_term` |

اسکیم کامل dataLayer برای هرکدام → `appendix/data-dictionary.md`. **این ۶ رویداد به GA4 می‌روند؛ یکتانت و تپ‌سول فقط دو رویداد `purchase` و `generate_lead` (با مقدار) نیاز دارند.**

## نکات اجرایی (از تجربه)

- **صفحه‌ی `/model/...` (انتخاب سایز) را فراموش نکن:** در این سایت «خرید» دو مرحله دارد (PDP → انتخاب سایز). اگر `view_item` فقط روی PDP باشد، مدل‌هایی که کاربر مستقیم با لینک/جستجو باز می‌کند نمی‌آیند. هر دو صفحه = یک `view_item`.
- **قیمت «۰ تومان» (محصولات استعلامی):** روی این‌ها `price` را 0 بگذار **و** CTA واقعی‌شان «استعلام قیمت» است → کلیک CTA = `generate_lead` با `lead_method=form` یا `whatsapp`. یعنی محصولات ۰ تومانی «بدون معیاری» نیستند؛ لیدساز هستند.
- **purchase فقط در صفحه‌ی موفقیت پرداخت:** اگر در صفحه‌ی گیت‌وی/مبانی بگذارید، پرداخت‌های شکست‌خورده هم می‌شمارید. وب‌بیت URL موفقیت پرداخت دارد — با تیم فنی هماهنگ شود.
- **به شبکه‌ها بیشتر از ۲ تبدیل نده:** yektanet/tapsell با ۲ تبدیل (خرید + لید) کار می‌کنند. تبدیل اضافی = هزینه‌ی بیشتر + همپوشانی.
- **دفتر تغییرات GTM** (تسک ۶) را جدی بگیر: ۳ ماه بعد وقتی چیزی عجیب شد، این دفتر نجاتت می‌کند.
